# 標準ライブラリとプラットフォーム SDK

Asuka には 2 種類のパッケージが付属しています。どちらも `asuka` CLI に含まれているので、`asuka add` は要りません。インポートすればそのまま使えます。

- **標準ライブラリ**（`std/...`）：言語そのもののライブラリです（JSON、時刻、URL、正規表現、ファイル、HTTP、SQLite、store、Markdown、グラフなど）。どのプラットフォームでも同じように動きます。
- **プラットフォーム SDK**（`platform/...`）：デバイス（カメラ、位置情報、Bluetooth、センサー）、OS のサービス（通知、共有シート、Dock とトレイ、キーチェーン）、ストア（購入、Apple Pay、レビュー）をラップするパッケージです。

```asuka
import std/http
import std/store

state units = store.read("units", "metric")
```

以前のバージョンの `asuka/...` というパスをインポートすると、そのパッケージの今の名前が表示されます（`asuka/camera is platform/camera now`）。

標準ライブラリのほとんどのパッケージはプラットフォームのコードを必要としません。Asuka で書かれていて、Asuka で書けない部分はランタイム自身の C が担うので、どこでも同じように動きます（`std/json`、`std/math`、`std/embed` はコンパイラーの一部です）。それ以外のパッケージ（とプラットフォーム SDK のほとんど）は、ほかの[ネイティブパッケージ](native.md)と同じで、各プラットフォームがそれぞれの API で動かします（iOS と macOS では URLSession、Android では Android 自身のクラス、Web ではブラウザーの API、Windows と Linux では C）。そのため、そのプラットフォームのアプリと同じように振る舞います。

## 標準ライブラリ：`std/`

| パッケージ | 内容 |
|---|---|
| [`std/json`](std/json.md) | `json.decode<T>(text)` と `json.encode(value, indent:)`：コンパイラーが `T` について知っていることにもとづく、型付きの JSON。`json.parse(text)` は `json.Value`（`.null`、`.bool`、`.int`、`.float`、`.string`、`.array`、`.object`。`get(key)`、`at(i)`、`asString()` など）を返します：形の決まっていない JSON をそのまま扱え、単独でも構造体のフィールドとしても使えます |

| [`std/embed`](std/embed.md) | パッケージのファイルをアプリに組み込みます：`embed.text(path)`、`bytes(path)`、`json<T>(path)`（`T` として読み、コンパイル時に検査）、`texts(glob)` と `files(glob)`（`[パス: テキスト]`、`[パス: バイト列]`） |
| [`std/time`](std/time.md) | `time.now()`、`time.date(2026, 3, 7, hour: 9, zone: .utc)`、`time.unix(s)`、`time.parse(rfc3339)`：`Time` を返します。タイムゾーン（`.local`、`.utc`、`.fixed(seconds:)`）付きの時刻で、壁時計としての `year`、`month`、`day`、`hour`、`minute`、`second`、`nanosecond`、`weekday` を持ちます。メソッドは `format("EEE d MMM, HH:mm")`（Unicode の日付パターン、英語で出力）、`rfc3339()`、`add(d)`、`sub(t)`（`Duration` を返す）、`addDate(years:, months:, days:)`、`isBefore`、`isAfter`、`compare`、`sameDay`、`startOfDay`、`truncate(d)`、`inZone`、`utc`、`local`、`unix`、`unixMilli`、`unixNano` です。ほかに `time.monotonic()`（前にしか進まない `Duration`）、`time.since(t)`、`time.ticks(1s)` と `time.ticker(1s)`（時刻のストリーム） |
| [`std/decimal`](std/decimal.md) | `Decimal`：金額などのための正確な十進数。`Decimal.parse("19.99")`（`Decimal?` を返す）、`Decimal.of(1999, exponent: -2)`、`.zero`、`.one`。`+`、`-`、`*` は正確（`price * 3` も可）、`/` は有効数字 18 桁、ほかに `%`、`-x`、`<` などの比較。`divided(by:, places:, mode:)` と `rounded(places:, mode:)` は `RoundingMode`（`down`、`up`、`ceiling`、`floor`、`halfUp`、`halfDown`、`halfEven`）で丸めます。`string()`、`formatted(currency:)`（表示している言語の書き方。`i18n.formatCurrency` と同じ）、`int()`、`float()`、`abs()`、`sign()`。結果の桁が int に収まらなければ "integer overflow" を投げます |
| [`std/url`](std/url.md) | `url.parse(text)`：`URL?` を返します。`scheme`、`user`、`host`、`port`、`path`、`rawQuery`、`fragment` と、`query(name)`、`queryAll(name)`、`text()`、`resolve(ref)`（RFC 3986）を持ちます。ほかに `url.resolve(base, ref)`、`escape`、`unescape`、`pathEscape`、`pathUnescape`、`encodeQuery(map)`（名前順）、`parseQuery(raw)` |
| [`std/regex`](std/regex.md) | `regex.compile(pattern)`（不正なパターンではエラーを投げる）：`Regex` を返し、`matches`、`find`、`findAll`、`findRange`、`findSubmatch`、`findAllSubmatches`、`replace(text, with: "$1")`、`replaceEach(text, f:)`、`split`、`groupNames` を持ちます。`regex.quote(text)` もあります。構文は RE2 で、照合は線形時間です（バックトラックしません） |
| [`std/encoding`](std/encoding.md) | `base64Encode`、`base64URLEncode`（パディングなし）、`base64Decode`（どちらのアルファベットも可）、`hexEncode`、`hexDecode` |
| [`std/crypto`](std/crypto.md) | `sha256`、`sha512`、`sha1`、`hmacSHA256(key:, data:)`、`randomBytes(n)`（システムの乱数源）、`uuid()`（バージョン 4）、`equal(a, b)`（定数時間で比較）、Ed25519（RFC 8032）の `ed25519Verify(publicKey, message, signature)`、`ed25519Sign(privateKey, message)`、`ed25519PublicKey(privateKey)`、`ed25519NewKey()` |
| [`std/html`](std/html.md) | `escape(text)` と `unescape(text)`（数値参照と、テキストでよく使われる名前付き参照） |
| [`std/random`](std/random.md) | `random.int(1, 6)`（両端を含む）、`float()`、`chance(p)`、`pick(items)`、`shuffled(items)`、`seed(n)` |
| [`std/fs`](std/fs.md) | `fs.appDir()`（アプリ自身のディレクトリ）、`home()`（ユーザーのホームディレクトリ）、`tempDir()`、`abs(path)`、`join([…])`、`clean`、`dir`、`base`、`ext`。ブロックするため `spawn { }` の中で呼ぶもの：`readDir`（`Entry`：`path`、`name`、`isDir`、`size`、`modified`）、`walk(dir, skip:)`（ディレクトリの下にあるものすべて）、`stat`、`read`、`readText`、`write`、`writeText`、`append`、`appendText`、`copy`、`rename`、`mkdirAll`、`remove`、`removeAll`、`exists`。失敗すると `FsError`（`.notFound(path)`、`.exists`、`.denied`、`.notDirectory`、`.isDirectory`、`.notEmpty`、`.failed(path, reason)`）を投げます |
| [`std/os`](std/os.md) | プログラムが動くプロセス（[プログラム](programs.md)）：`os.args()`、`program()`、`env(name)`、`environ()`、`cwd()`、`exit(code)`。stdin は `readLine()`、`readAll()`、`lines()`（別のスレッドで読む stream）。`eprint(text)`、`writeTo(.stderr, text)`、`terminal(.stdout)`、`signals(kinds)`（Ctrl-C、終了、ハングアップをプログラム自身で扱う。扱わなければ Ctrl-C は非同期の main をキャンセルし、defer を実行して終了コード 130 で終わる）。`os.fake(args:, env:, stdin:)` と `FakeOS.run(main)` は、テストでプログラムの main を本物のプロセスと同じように実行します（終了コード、stdout、stderr）。スマートフォンと Web のアプリでは引数も stdin もなく、`exit` はエラーを投げます |
| [`std/flag`](std/flag.md) | `flag.parse<T>(os.args())`：コンパイラーが `T` について知っていることから、コマンドラインをオプションの構造体（デフォルト値のあるフィールドが `--フィールド名`、ドキュメントコメントがヘルプ、最初の単語 `-x` が短い名前。デフォルト値のないものは位置引数）か、サブコマンドの enum に読み込みます。`--help`、`--version`、候補を示す誤りの報告と終了コード 2。`tryParse<T>`（`FlagError`）、`help<T>()` |
| [`std/term`](std/term.md) | プログラムが動く端末（[プログラム](programs.md#端末stdterm)）：`term.bold(text)`、`dim`、`italic`、`underline`、`red`、`green` など、そして `Style(color:, background:, bold:…)` の `paint(text)`。スタイルは端末のときだけ表示（`NO_COLOR`、`FORCE_COLOR`、`TERM=dumb` に従う。`colors(.stdout)`、`--color` フラグには `setColors(.always)`）。`prompt(question, default:)`、`confirm(question, default:)`、`secret(question)`（エコーなし）は stderr に質問し、テストでは `os.fake` の stdin が答える。`width()`、`height()`。スマートフォンと Web には端末がない |
| [`std/command`](std/command.md) | ほかのプログラムを、シェルを通さずに実行します：`command.run(program, args, cwd:, env:, stdin:, check:)`（`Output`：`code`、`stdout`、`stderr`、`text()`）、`status(…)`（実行中のプログラムの標準ストリームを使う）、`start(…)`（`Process`：`lines()`、`stdout()`、`write`、`closeStdin`、`wait`、`output`、`kill`）。待機がキャンセルされるとプログラムも終了します。`bundled(name)`：アプリ自身のプログラム（asuka.toml の `[bin]`）のパス。fork と exec、CreateProcess。テストでは `command.fake()`。プログラムとデスクトップアプリで使え、スマートフォンと Web では `unsupported` |
| [`std/i18n`](std/i18n.md) | アプリが表示する言語：`i18n.locale()`、`setLocale(tag)`、`languages()`、`preferredLanguages()`、`isRTL()`、`autonym(tag)`、`region()`。その言語の書き方で数値と日付を書く：`formatNumber`、`formatInt`、`formatPercent`、`formatDecimal`、`formatCurrency(amount, currency)`、`formatDate(t, date:, time:)`。アプリのメッセージは `tr.key(…)` で使います（[多言語対応](i18n.md)を参照） |
| [`std/http`](std/http.md) | `http.get`、`http.post`、`http.postJSON`、`http.request`、`http.download`（届くそばからファイルに書き、進捗を知らせる）、`http.stream`（送られてくるそばから読むボディ：断片、`lines()`、`events()`）、`http.events`（サーバー送信イベント。指定すれば再接続）、`http.loopback`（サインインのリダイレクトを受けるループバック上のサーバー）：リクエストはプラットフォーム自身のクライアントを通るので、プロキシ、信頼された証明書、キャッシュ、Cookie はシステムと同じように働きます。`Response` には `status`、`url`、`headers`、`body`、`text()`、`json<T>()`、`ok()` があります |
| [`std/websocket`](std/websocket.md) | `websocket.connect(url, headers:, protocols:)`：`WebSocket` を返し、`send(text)`、`sendBinary(data)` で送り、`messages` から受け取り（`.text`、`.binary`）、`close(code:, reason:)` で閉じます。各プラットフォーム自身のクライアント（URLSession、OkHttp、ブラウザー、WinHTTP、libsoup）を通ります |
| [`std/store`](std/store.md) | `store.read(key, default)`、`store.write(key, value)`、`store.remove(key)`、`store.flush()`、`store.dir()`：起動をまたいで JSON として保持する小さな値。保存先はプラットフォームの環境設定です（UserDefaults、SharedPreferences、`localStorage`、Windows と Linux ではファイルで、変更の少し後に書き込まれます） |
| [`std/watch`](std/watch.md) | `watch.path(dir, ignore:, recursive:, attributes:)` は `Watch` を返します。`root` と、`Event` のまとまりのストリームである `events`（`op`：create、write、remove、rename、attrib、overflow。`path`、`oldPath`）を持ちます。各デスクトップ OS 自身のファイルイベントを使います。スマートフォンと Web では使えません |
| [`std/sqlite`](std/sqlite.md) | `sqlite.open(name)`（アプリのデータディレクトリ内のファイル、絶対パス、または `":memory:"`）は `DB` を返します：`migrate(steps)`、`exec(sql, args)` と `query<T>(sql, args)`（非同期で、メインスレッドの外で実行。行は `T` に直接デコードされ、構造体のフィールドは列名で対応します）、`watch<T>(sql, args)`（`Live<T>` ストア：`rows`、`loading`、`error`。引数が変わったとき、読み取るテーブルに書き込みがあったときに再実行されます）、`changed()`、`close()`。SQLite はアプリに組み込まれます（[ライブラリ](data.md#ライブラリ)）。Web ではページのワーカーで動きます |
| [`std/storage`](std/storage.md) | `storage.Value(key, default)`：`value` がデバイスに保持されるストア（std/store を使います）。追跡され、変わると書き込まれます。`reset()`、`storage.flush()`、`storage.dirName()` |
| [`std/lottie`](std/lottie.md) | `lottie.View(source)`（`bind playing`、`bind progress`、`loop`、`speed`、`segment`、`marker`、`fit`、`overrides`。`complete`、`loaded`）：各プラットフォームのプレーヤーによる Lottie と dotLottie。Windows と Linux ではまだありません（[コンポーネント](components.md)） |
| [`std/svg`](std/svg.md) | アプリのコンパイル時に解析される `svg.Icon(markup)` と、`svg.View(icon) { color }`。`svg.Shape(layers)`：アプリが描くパスで、自分の枠に追従します（[コンポーネント](components.md)） |
| [`std/base`](std/base.md) | 振る舞いだけを持ち見た目を持たないコンポーネント。アプリがスタイルを付け、どこでも同じように動きます：`Select`、`Combobox`、`Menu`、`Dialog`、`Popover`、`Tooltip`、`Tabs`、`Checkbox`、`Switch`、`RadioGroup`、`Slider`、`Field` と `Form`、トーストなど。それぞれが状態、キーボードとフォーカス、スクリーンリーダー、ウィンドウの上での位置を扱います（[独自の見た目](components.md#独自の見た目)） |
| [`std/chart`](std/chart.md) | `chart.View(series) { labels, label, low, high, grid, format }`。`chart.Series(name:, kind: .bar \| .line \| .area \| .points, values:, smooth:, color:)`：Asuka で書かれ、`svg.Shape` で描かれます（[コンポーネント](components.md)） |
| [`std/markdown`](std/markdown.md) | `markdown.View(text) { streaming }` と `markdown.heal(text)`：Markdown をプラットフォームのスタイル付きテキストとして表示し、ストリーミング中は届くそばから補修します（[コンポーネント](components.md)） |

## プラットフォーム SDK：`platform/`

これらのパッケージは各プラットフォームが持つ機能をラップするので、できることはプラットフォームごとに異なります。機能がないプラットフォームでは、パッケージがそう伝えます（`unsupported` エラー、または代わりの結果）。違いは[プラットフォームの比較](parity.md)のページにまとめてあります。

| パッケージ | 内容 |
|---|---|
| [`platform/integrity`](platform/integrity.md) | `integrity.supported()`、`generateKey()`、`attestKey(id, challenge)`、`assertion(id, data)`（iOS と Mac の App Attest）。`prepare(cloudProjectNumber:)`、`token(requestHash:)`（Play Integrity） |
| [`platform/js`](platform/js.md) | `js.eval(script, timeout:)`：プラットフォーム自身のエンジン（WKWebView、Android の WebView、WebView2、WebKitGTK、サンドボックス化した frame）で JavaScript を画面外で実行し、その値を JSON で返します。`js.JsError.timeout` |
| [`platform/apps`](platform/apps.md) | `apps.list()`、`apps.search(apps, query)`（ランチャーと同じ順位付け：名前そのもの、名前の先頭、単語の先頭か各単語の頭文字の並び、どこかに含まれる、文字が順に含まれる。大文字小文字とアクセントは区別しない）、`apps.icon(app, size)`（PNG ファイルのパス）、`apps.open(app)`：macOS、Windows、Linux にインストールされているアプリ。スマートフォンとウェブでは `AppsError.unsupported` を投げます |
| [`platform/dock`](platform/dock.md) | `dock.setProgress(Progress(value:, state:))` と `dock.requestAttention(.critical)`：アプリのアイコンへの進捗表示と注意喚起。macOS の Dock、Windows のタスクバー、Linux のランチャー（デスクトップに Unity のランチャー API があるとき）。スマートフォンとウェブでは何もしません |

ネイティブパッケージのコードがないプラットフォーム（`asuka test` で動かすアプリにはまったくありません）では、それを必要とする処理は `unsupported` エラーを投げます。そのとき `std/store` は何も保存せず、読み込むとデフォルト値が返ります。

`asuka test` では実行のたびに同じ結果になります。`time.now()` は 2026-01-01T00:00:00Z から始まり、テストの時間（`sleep`）に合わせてだけ進みます。ローカルのタイムゾーンは UTC で、各テストには `fs.appDir()` として専用の空のディレクトリがあります。Web ではアプリにまだディレクトリがないので、`std/fs` の呼び出しはエラーを投げます。

デバイスまわりのパッケージ（`location`、`sensors`、`purchase`、`pay`、`appleauth`、`nfc`、`bluetooth`）にはテスト用のフェイクがあります。`location.fake()` や `purchase.fake(products)` などは、プラットフォームの実装の代わりに、テストが操作する Asuka の実装（端末を動かす、購入を承認する、タグをかざす、ペリフェラルを加える）をパッケージに与えます。詳しくは[テスト](testing.md#プラットフォームのサービスとネイティブパッケージ)を参照してください。

## ここにないパッケージ

標準ライブラリにもプラットフォーム SDK にもないものは[パッケージ](packages.md)（`asuka add`）から入手します。何もラップしていないプラットフォームの API なら、自分でネイティブパッケージを作ります（[ネイティブコード](native.md)）。
