# format-spec

値に合わない補間の書式。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

補間のコロンの後ろの書式（`"{price:>8.2f}"`）は、値をどう書き出すかを決めます：`[[fill]align][sign][#][0][width][,|_][.precision][type]`。Python や Rust と同じ書き方です。符号、`#`、`0`、桁区切り、型は数値のためのもので（`x`、`X`、`o`、`b` は整数の基数、`f`、`e`、`%` は浮動小数点数の書き方）、それ以外の値はテキストとして書き出され、埋め文字、揃え、幅、精度（表示する最大の文字数）だけを指定できます。書式はコンパイラーが読むので、間違いは書いた場所で報告されます。

## 直し方

メッセージのとおり、値の型に合った書式を書きます：`{n:>6}`、`{x:.2f}`、`{n:#x}`、`{name:<12}`。

## 誤った例

```asuka
fn price(cents: int) -> string = "{cents:.2}"
```

## 正しい例

```asuka
fn price(cents: int) -> string = "{float(cents) / 100:.2f}"
```
