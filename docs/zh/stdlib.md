# 标准库与平台 SDK

Asuka 自带两组包。它们都随 `asuka` 命令行工具一起提供，不需要 `asuka add`：导入就能用。

- **标准库**，`std/...`：语言自己的库（JSON、时间、URL、正则表达式、文件、HTTP、SQLite、store、Markdown、图表……），在每个平台上都一样。
- **平台 SDK**，`platform/...`：封装设备（相机、定位、蓝牙、传感器）、操作系统服务（通知、分享面板、Dock 和托盘、钥匙串）或应用商店（购买、Apple Pay、评分）的包。

```asuka
import std/http
import std/store

state units = store.read("units", "metric")
```

导入旧版本的 `asuka/...` 路径时，编译器会告诉你这个包现在叫什么（`asuka/camera is platform/camera now`）。

标准库的大多数包不需要平台代码：它们用 Asuka 写成，Asuka 表达不了的部分由运行时自己的 C 完成，所以在每个平台上的行为都一样（`std/json`、`std/math` 和 `std/embed` 是编译器的一部分）。其余的包（以及平台 SDK 的大多数包）和别的[原生包](native.md)一样：每个平台用自己的 API 来实现（iOS 和 macOS 上用 URLSession，Android 上用它自己的类，Web 上用浏览器的 API，Windows 和 Linux 上用 C），所以它们的行为和平台原生应用里的一致。

## 标准库：`std/`

| 包 | 内容 |
|---|---|
| [`std/json`](std/json.md) | `json.decode<T>(text)` 和 `json.encode(value, indent:)`：带类型的 JSON，依据编译器对 `T` 的了解来读写（结构体按字段名读取，Web API 的 `html_url` 这类蛇形键名也会读进 `htmlUrl`）；`json.parse(text)` 返回 `json.Value`（`.null`、`.bool`、`.int`、`.float`、`.string`、`.array`、`.object`；`get(key)`、`at(i)`、`asString()` ……）：任意结构的 JSON，原样保留，可以单独使用，也可以作为结构体的字段；在需要 `json.Value` 的地方，任何 JSON 能表示的值都会自动转换成它（`["port": port, "tls": true]` 作为 `[string: json.Value]`） |
| [`std/toml`](std/toml.md) | TOML 1.0，用于配置文件：`toml.decode<T>(text)`（按字段名读进结构体，`rust-version` 会读进 `rustVersion`），`toml.encode(value)`（先写普通的键，再写 `[表]` 和 `[[表数组]]`），`toml.parse(text)`（任意文档，读成 `json.Value`）；日期和时间读成它们的 RFC 3339 文本；错误会给出 `行:列` 和对应的键 |
| [`std/csv`](std/csv.md) | CSV（RFC 4180，读法与 Go 的 `encoding/csv` 一致）：`csv.parse(text)`（`[[string]]`），`csv.decode<T>(text)`（按表头读进结构体：int、float、bool、枚举，空单元格对应可选字段的 none），`csv.encode(rows, header:, crlf:)`，`csv.stream<T>(lines)`（一次一行，来自 `os.lines()` 或命令的输出）；选项有 `separator:`（`"\t"`）、`comment:`、`trimLeadingSpace:`、`lazyQuotes:`、`flexible:`；错误会给出 `行:列` |
| [`std/template`](std/template.md) | 用 Jinja 语法的模板生成文本（[程序](programs.md#用模板生成文本stdtemplate)）：`template.parse(source, name:, escape:, filters:)`（得到 `Template`，只解析一次：`render(data)` 传入结构体或 map，`renderValue(json)`），`parseAll(sources)`（按名字互相 include 和 extend 的 `Templates`），`render(source, data)`；`{{ x \| filter }}`、`{% if %}`、`{% for %}`（`loop.index`……）、`{% set %}`、`{% include %}`、`{% extends %}` 和带 `super()` 的 `{% block %}`、`{% raw %}`；过滤器（`upper`、`default`、`join`、`sort`、`truncate`、`indent`、`round`、`json`、`escape`、`safe`……）和测试（`is defined`、`is even`……）；单独占一行的语句会连同这一行去掉，`{{-` `-}}` 去掉空白；`escape: .html` 或以 `.html` 结尾的名字会转义 HTML；`TemplateError` 给出 `名字:行:列` |
| [`std/semver`](std/semver.md) | 语义化版本（SemVer 2.0.0）：`semver.parse(text)`（得到 `Version`：`major`、`minor`、`patch`、`prerelease`、`build`；按优先级用 `<` 比较、`sorted()` 排序，`compare`、`next(.minor)`、`string()`），`parseRange(text, includePrerelease:)`（npm 的语法，与 `Bun.semver` 相同：`^1.2.3`、`~1.2`、`1.x`、`>=1.0 <2.0`、`1.2 - 2.3`、`\|\|`，也接受 Cargo 的逗号；得到 `Range`，有 `matches(v)`、`highest(versions)`、`lowest(versions)`），`satisfies(version, range)`、`maxSatisfying(versions, range)`、`compare(a, b)` |
| [`std/math`](std/math.md) | `sqrt`、`pow`、`exp`、`log`、`log2`、`log10`、`floor`、`ceil`、`round`、`sin`、`cos`、`tan`、`atan`、`atan2`、`clamp`、`random`、`randomInt`、`seed`、`pi` |
| [`std/embed`](std/embed.md) | 把包里的文件编进应用：`embed.text(path)`、`bytes(path)`、`json<T>(path)`（按 `T` 读取，编译时检查）、`texts(glob)` 和 `files(glob)`（`[路径: 文本]`、`[路径: 字节]`） |
| [`std/time`](std/time.md) | `time.now()`、`time.date(2026, 3, 7, hour: 9, zone: .utc)`、`time.unix(s)`、`time.parse(rfc3339)`（也认 RFC 9557 附带的时区：`…+01:00[Europe/Paris]`）：得到一个 `Time`，即带时区的时刻。时区可以是 `.local`、`.utc`、`.fixed(seconds:)`，也可以按名字取 IANA 时区：`try time.zone("America/New_York")`，历年的夏令时都算在内；规则来自 Asuka 自带的 tz 数据库，所以在每个平台上结果都一样。`Time` 只存时刻、时区和当时的偏移；挂钟上的各个字段是方法，用到时才算（和 Go 的 `time.Time` 一样）：`year()`、`month()`、`day()`、`hour()`、`minute()`、`second()`、`nanosecond()`、`weekday()`。其他方法有：`format("EEE d MMM, HH:mm zzz")`（Unicode 的日期模式，英文输出；`zzz` 是时区缩写，`VV` 是时区名）、`rfc3339()`、`add(d)`、`sub(t)`（得到 `Duration`）、`addDate(years:, months:, days:)`、`isBefore`、`isAfter`、`compare`、`sameDay`、`startOfDay`、`truncate(d)`、`inZone`、`utc`、`local`、`unix`、`unixMilli`、`unixNano`。另有 `time.zones()`（世界各地时区的名字）、`time.Zone.local.name()`（系统告知时，设备所在时区的名字）、`time.parseDuration("1h30m")`、`time.monotonic()`（只会向前走的 `Duration`）、`time.since(t)`、`time.ticks(1s)` 和 `time.ticker(1s)`（时刻的流） |
| [`std/decimal`](std/decimal.md) | `Decimal`：精确的十进制数，用于金额。`Decimal.parse("19.99")`（得到 `Decimal?`）、`Decimal.of(1999, exponent: -2)`、`.zero`、`.one`；`+`、`-`、`*` 精确计算（也可以 `price * 3`），`/` 保留 18 位有效数字，还有 `%`、`-x`、`<` 等比较；`divided(by:, places:, mode:)` 和 `rounded(places:, mode:)` 按 `RoundingMode`（`down`、`up`、`ceiling`、`floor`、`halfUp`、`halfDown`、`halfEven`）舍入；`string()`、`formatted(currency:)`（按当前语言的方式书写，同 `i18n.formatCurrency`）、`int()`、`float()`、`abs()`、`sign()`。结果的位数超出 int 能容纳的范围时，抛出 "integer overflow" |
| [`std/bigint`](std/bigint.md) | `BigInt`：任意大小的整数。`BigInt.of(n)`、`BigInt.parse(text, radix:)`（得到 `BigInt?`；和字面量一样可以写下划线和 `0x`）、`fromBytes(data, signed:)`（大端序；`signed` 为 true 时按补码读）、`fromFloat(x)`、`fromDecimal(d)`、`factorial(n)`、`random(below:)`（取自系统的安全随机数）、`.zero`、`.one`；`+`、`-`、`*`、`/`、`%`（和 `int` 一样向零取整；`+`、`-`、`*`、`/` 的右边也可以是 `int`，如 `n + 1`、`n * 3`），`-x`、`<` 等比较，以及 `==` 和哈希（可作 map 的键、放进集合）；`floorDiv`、`mod`、`divMod`（同 Python 的 `//`、`%`、`divmod`）、`quoRem`；`pow(e)`、`modPow(e, m)`（Montgomery 乘法）、`modInverse(m)`、`gcd`、`lcm`、`sqrt()`、`abs()`、`sign()`；按补码运算的位操作（与 Go、Python 一致）：`and`、`or`、`xor`、`not()`、`shiftLeft(n)`、`shiftRight(n)`、`bit(i)`、`setBit(i)`、`clearBit(i)`、`bitLength()`、`trailingZeros()`；`isProbablePrime(rounds:)`（先做 Baillie-PSW，再做 Miller-Rabin）；`string(radix:)`、`toInt()`（得到 `int?`）、`float()`、`decimal()`、`toBytes(size:, signed:)`、`formatted()`。打印出来是它的各位数字，JSON 把它写成一个完整的数字（也能从数字字符串读回）。乘法用 Karatsuba 算法，除法和进制转换都是次二次的：一百万位的数大约一秒就能打印出来 |
| [`std/collections`](std/collections.md) | `Heap<T>(by: less)`：优先队列，`pop` 按它的顺序给出最小的元素（`push`、`pop`、`pushPop`、`replace`：O(log n)；`peek`；`Heap.of(xs, by:)`，以及按 `<` 排序的 `Heap.min(xs)` 和 `Heap.max(xs)`：O(n)）；`SortedMap<K, V>` 和 `SortedSet<T>`：按键的顺序保存（B 树：`get`、`set`、`remove`、`insert`、`contains` 都是 O(log n)），提供 `first`、`last`、`popFirst`、`popLast`、`floor`、`ceiling`、`lower`、`higher` 和 `range(from:, to:)`（一个惰性的 `Seq`），默认按 `<` 排序，也可以用 `by:` 指定。它们都是值：复制的开销很小，修改时只复制改动的部分（SortedMap 只复制从根出发的那条路径）。双端队列就是数组（`pushFirst`、`popFirst`） |
| [`std/url`](std/url.md) | `url.parse(text)`：得到 `URL?`，含 `scheme`、`user`、`host`、`port`、`path`、`rawQuery`、`fragment`，以及 `query(name)`、`queryAll(name)`、`text()` 和 `resolve(ref)`（RFC 3986）；还有 `url.resolve(base, ref)`、`escape`、`unescape`、`pathEscape`、`pathUnescape`、`encodeQuery(map)`（参数名排序）、`parseQuery(raw)` |
| [`std/regex`](std/regex.md) | `regex.compile(pattern)`（模式有误时抛出错误）：得到 `Regex`，有 `matches`、`find`、`findAll`、`findRange`、`findSubmatch`、`findAllSubmatches`、`replace(text, with: "$1")`、`replaceEach(text, f:)`、`split`、`groupNames`；以及 `regex.quote(text)`。语法是 RE2 的，匹配时间是线性的（不回溯） |
| [`std/encoding`](std/encoding.md) | `base64Encode`、`base64URLEncode`（不补齐）、`base64Decode`（两种字母表都接受）、`hexEncode`、`hexDecode`；`base32Encode`、`base32Decode`（RFC 4648，`.standard` 或 `.hex` 字母表）；`utf16Encode`、`utf16Decode`（由 BOM 决定字节序；不合法的部分变成 U+FFFD）、`utf16DecodeStrict`；数字与字节互转，两种字节序都支持（`Endian`：`.little` 或 `.big`）：`readU16(data, at:, endian:)` … `readI64`、`readF32`、`readF64` 以及 `writeU8` … `writeF64`，变长整数（`writeUvarint`、`readVarint`，与 Go 和 Protocol Buffers 的编码相同），`Reader`（边读边前进：`try r.u32()`），`Writer`（依次追加：`w.u16(x)`、`w.data()`），`float32Bits`、`float64FromBits` |
| [`std/crypto`](std/crypto.md) | 所有平台（包括 Web）都是同一份 C 代码。哈希：`sha256`、`sha384`、`sha512`、`sha1`、`md5`（用于校验和，不用于安全）；`hmac(key, data, hash:)`、`hmacSHA256`、`hmacSHA512`；`hkdf`（RFC 5869）、`pbkdf2`；`randomBytes(n)`（来自系统的随机源）、`uuid()`（第 4 版）、`equal(a, b)`（常数时间比较）。认证加密：`seal(key, plaintext, additionalData:, cipher:)` 和 `open`（默认 XChaCha20-Poly1305 加随机 nonce；也支持 ChaCha20-Poly1305、AES-256-GCM、AES-128-GCM）、`sealWithNonce`、`openWithNonce`、`newKey()`；数据被改动时 `open` 抛出 `CryptoError.notAuthentic`。密码（在另一个线程上计算）：`hashPassword`（argon2id，RFC 9106，输出 PHC 字符串）、`hashPasswordBcrypt`、`verifyPassword`（读 argon2 和 bcrypt 哈希）、`argon2id`（从密码派生密钥）。签名：`verify(key, message, signature, scheme:)` 和 `sign`，支持 RSA（PKCS#1 v1.5、PSS）、ECDSA（P-256、P-384、P-521）和 Ed25519，密钥可从 PEM、DER、JWK 和 JWK Set 读入（`publicKey`、`privateKey`、`publicKeys` 等），也能读 OpenSSH 的私钥；加密的私钥用 `decryptPrivateKey(pem, password:)` 读（PKCS#8 的 PBES2、OpenSSL 和 OpenSSH 的格式；密码不对时为 `CryptoError.wrongPassword`），用 `key.encryptedPEM(password:)` 写，`newPrivateKey()` 生成密钥，`SignatureScheme.jws(alg)` 用于 JWT；直接处理 Ed25519 原始密钥的有 `ed25519Verify`、`ed25519Sign`、`ed25519PublicKey`、`ed25519NewKey` |
| [`std/html`](std/html.md) | `escape(text)` 和 `unescape(text)`（数字引用，以及文本中常用的命名引用） |
| [`std/random`](std/random.md) | `random.int(1, 6)`（包含两端）、`float()`、`chance(p)`、`pick(items)`、`shuffled(items)`、`seed(n)` |
| [`std/fs`](std/fs.md) | `fs.appDir()`（应用自己的目录）、`configDir()`（它的设置）、`cacheDir()`（可以重新生成的内容）、`logDir()`（它的日志）、`home()`（用户的主目录）、`tempDir()`、`abs(path)`、`join([…])`、`clean`、`dir`、`base`、`ext`；`await fs.readAsset(name)`：读取应用某个资源的字节，所有平台都可以用；以及会阻塞、应放在 `spawn { }` 里调用的：`readDir`（返回 `Entry`：`path`、`name`、`isDir`、`size`、`modified`）、`walk(dir, skip:)`（目录下所有层级的内容）、`stat`、`read`、`readText`、`write`、`writeText`、`append`、`appendText`、`copy`、`rename`、`mkdirAll`、`remove`、`removeAll`、`exists`、`glob(pattern)`、`matches`、`chmod`、`symlink`、`readLink`；`open(path, mode:)`（返回 `File`：`readLine`、`read`、`readAll`、`write`、`seek`、`size`、`flush`、`close`，都是异步的，分段读写）和 `lines(path)`（流：任意大小的文件）。失败时抛出 `FsError`（`.notFound(path)`、`.exists`、`.denied`、`.notDirectory`、`.isDirectory`、`.notEmpty`、`.failed(path, reason)`） |
| [`std/compress`](std/compress.md) | gzip、zlib 和原始 DEFLATE，在所有平台上结果一致：处理字节用 `compress.encode(data, format:, level:)` 和 `decode(data, format:, limit:)`；`encodeFile(from:, to:)` 和 `decodeFile(from:, to:)` 逐块处理文件（放在 `spawn { }` 里调用）。解压出的数据超过 `limit:`（默认 1 GB）时抛出 `.tooLarge`，数据不是对应格式时抛出 `.corrupt`；还有这些格式所用的校验和 `crc32(data, previous:)` 和 `crc32c`（Castagnoli） |
| [`std/archive`](std/archive.md) | zip 和 tar 归档（`.zip`、`.tar`、`.tar.gz`；需要时使用 zip64，长文件名用 pax），格式由文件内容判断：逐块读写文件的 `archive.list(path)`（返回 `Entry`：`name`、`kind`、`size`、`compressedSize`、`modified`、`mode`、`target`）、`read(path, name:)`、`extract(path, to:, limit:)`、`create(path, from:)`（放在 `spawn { }` 里调用）；处理字节用 `entries(data)`、`decode(data)` 和 `encode(files, format:)`。解压时会拒绝落到目标目录之外的条目（`.unsafePath`：`..`、绝对路径、经过链接的路径），超过 `limit:` 时停止（`.tooLarge`） |
| [`std/os`](std/os.md) | 程序运行时所在的进程（[程序](programs.md)）：`os.args()`、`program()`、`env(name)`、`environ()`、`cwd()`、`exit(code)`；stdin：`readLine()`、`readAll()`、`lines()`（一个 stream，在另一个线程上读取）；`writeTo(.stderr, text)`（写一行用 prelude 的 `eprint`）、`writer(.stdout)`（一个 `Writer`：`write(text)`、`writeBytes(data)`、`flush()`；把多次写入攒在缓冲区里一块一块地写出，程序结束时写出剩下的内容）、`terminal(.stdout)`；`signals(kinds)`（由程序自己处理 Ctrl-C、终止和挂断信号；不处理时，Ctrl-C 会取消异步的 main，执行它的 defer，退出码为 130）；进程和机器：`hostname()`、`pid()`、`ppid()`、`user()`（一个 `User`：`name`、`home`、`uid`、`gid`）、`platform()`（一个 `Platform`）、`arch()`（`.arm64`、`.amd64`……）、`executable()`（程序自己的文件，链接已解析）。`os.fake(args:, env:, stdin:)` 和 `FakeOS.run(main)`：在测试里像真正的进程那样运行程序的 main（得到退出码、stdout 和 stderr）。手机和 Web 上的应用：没有参数和 stdin，`exit` 会抛出错误 |

如果某个平台没有原生包的代码（比如由 `asuka test` 运行的应用，它没有任何平台代码），用到它的地方会抛出 `unsupported` 错误；这时 `std/store` 什么也不保存，读取时返回默认值。

`asuka test` 让每次运行都可重复：`time.now()` 从 2026-01-01T00:00:00Z 开始，只随测试的时间（`sleep`）前进，本地时区是 UTC，每个测试都有一个属于自己的空目录作为 `fs.appDir()`，它的 `configDir()`、`cacheDir()` 和 `logDir()` 也都在这个目录里。Web 上应用还没有自己的目录，所以 `std/fs` 的调用在那里会抛出错误。

设备相关的包（`location`、`sensors`、`purchase`、`pay`、`appleauth`、`nfc`、`bluetooth`）都为测试提供了替身：`location.fake()`、`purchase.fake(products)` 等会把一个由测试驱动的 Asuka 实现换给这个包，代替平台的实现（移动设备位置、批准一笔购买、轻触一个标签、添加一个外设），参见[测试](testing.md#平台服务与原生包)。

## 标准库之外的包

标准库和平台 SDK 都没有的功能，可以来自一个[包](packages.md)（`asuka add`）；如果是还没有人封装过的平台 API，就写一个你自己的原生包（[原生代码](native.md)）。
