# format-spec

插值的格式和它的值对不上。

编译器报告的错误：修正之前程序无法构建。

## 原因

插值里冒号后面的格式（`"{price:>8.2f}"`）决定值怎么写出来：`[[fill]align][sign][#][0][width][,|_][.precision][type]`，和 Python、Rust 的写法一样。符号、`#`、`0`、分组和类型只用于数字（`x`、`X`、`o`、`b` 是整数的进制，`f`、`e`、`%` 是浮点数的写法）；其他值按它们的文本写出，只能指定填充字符、对齐、宽度和精度（最多显示的字符数）。格式由编译器读取，所以写错了会在写的地方报出来。

## 如何修正

按值的类型写格式，参照消息的说明：`{n:>6}`、`{x:.2f}`、`{n:#x}`、`{name:<12}`。

## 错误示例

```asuka
fn price(cents: int) -> string = "{cents:.2}"
```

## 正确示例

```asuka
fn price(cents: int) -> string = "{float(cents) / 100:.2f}"
```
