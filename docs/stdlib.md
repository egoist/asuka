# The standard library and the platform SDK

Asuka comes with two sets of packages. The `asuka` CLI carries both, so
they need no `asuka add`: import one and use it.

- **The standard library**, `std/...`: the language's own library (JSON,
  time, URLs, regular expressions, files, HTTP, SQLite, the store,
  Markdown, charts...), the same on every platform.
- **The platform SDK**, `platform/...`: what wraps a device (the camera,
  location, Bluetooth, the sensors), an operating system's service
  (notifications, the share sheet, the Dock and the tray, the keychain)
  or a store (purchases, Apple Pay, reviews).

```asuka
import std/http
import std/store

state units = store.read("units", "metric")
```

An import of the `asuka/...` paths of earlier versions says what the
package is now (`asuka/camera is platform/camera now`).

Most of the standard library needs no platform code: it's Asuka, and
what Asuka can't say is the runtime's own C, so it works the same
everywhere (`std/json`, `std/math` and `std/embed` are part of the compiler). The
rest of it, and most of the platform SDK, are
[native packages](native.md) like any other: each platform runs them
with its own APIs (URLSession on iOS and macOS, Android's own classes,
the browser's on the web, C on Windows and Linux), so they behave as
they do for the platform's own apps.

## The platform SDK: `platform/`

from one platform to another: a package says where it has nothing (an
`unsupported` error, or a fallback), and the [parity](parity.md) page
compares them.

Where a platform has no code for a native package (an app run by
`asuka test`, which has none), what needs it throws an `unsupported`
error; `std/store` keeps nothing then, and reads give their defaults.

`asuka test` makes runs repeat: `time.now()` starts at
2026-01-01T00:00:00Z and moves only as the test's time does (`sleep`),
the local zone is UTC, and each test has an empty directory of its own
as `fs.appDir()`. On the web the app's directory is the page's, kept in
the browser's storage ([The app's files](web.md#the-apps-files)).

The device's packages (`location`, `sensors`, `purchase`, `pay`,
`appleauth`, `nfc`, `bluetooth`) have fakes for tests: `location.fake()`,
`purchase.fake(products)` and the others give the package an Asuka
implementation a test drives (it moves the device, approves a purchase,
taps a tag, adds a peripheral) in place of the platform's. See
[Testing](testing.md#platform-services-and-native-packages).
